# SyncMaxx
The greatest cross-platform sync app you will ever experience. You'll switch from KDE Connect.

## What's better
**UI**: Literally on every single platform, SyncMaxx will beat KDE Connect by a mile.
<br>
**Resources**: Lighter on resource usage.
<br>
**Support**: Supports ancient versions of Android. Supports MacOS BigSur and above. Supports every Linux distro possible (Minimum hardware requirements will be listed below).
## Versions
| Version       | Software Requirements                 | Hardware Requirements                    |
| ------------- | ------------------------------------- | ---------------------------------------- |
| SyncMaxx      | Android 5.0+                          | Snapdragon 400 / MT6582, 1 GB RAM.       |
| SyncMaxx Air  | MacOS BigSur+                         | Any Mac that is running BigSur.          |
| SyncMaxx Hub  | Any Linux Distro. (GNOME Recommended) | Pentium 4 / Athlon 64, 1 GB RAM.         |
| SyncMaxx PC   | Windows 10+ (x86-64)                  | Pentium 4 / Athlon 64, 2 GB RAM.         |
## Features
**Quick Notification Push**: Pushes notifications from your Android to your Mac, Linux PC, and Windows PC.
